# MobCine
Aplicação mobile desenvolvida em React Native (Expo) para busca e gerenciamento de filmes, consumindo a API pública do TMDB.
O projeto foi feito para que o usuário tenha acesso a filmes e possa ler sobre eles e favoritar caso tenha tido interesse.
O mesmo usuário deve criar uma conta ou se logar em uma caso ja tenha cadastro.

## Funcionalidades

- **Autenticação Local**: Cadastro e login de usuários salvos no dispositivo.
- **Busca de Filmes**: Pesquisa em tempo real com *debounce* para otimizar requisições.
- **Listagem**: Exibição dos filmes populares do TMDB.
- **Detalhes do Filme**: Banner, nota, sinopse, gêneros e duração.
- **Favoritos**: Adicionar e remover filmes salvos no armazenamento local.

## Como executar:
- Node.js instalado
- Aplicativo **Expo Go** no celular (Android/iOS)
- Após isso clone o repositório
